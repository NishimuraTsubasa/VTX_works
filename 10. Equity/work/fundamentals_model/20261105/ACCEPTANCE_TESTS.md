# 実装・検収テスト仕様

この一覧は次の実装担当者が作成・実行するテストの要件である。同梱の単一ファイルサンプルには39項目の自動テストを実装した。ただし、以下の全項目を現行実データ・現行プロジェクトで通過済みという意味ではない。技術的なPASSは、実データの投資成績を保証しない。

| ID | テスト | 期待する結果 |
|---|---|---|
| T01 | 13本の役割・グループ定義が未確定 | 実データの実行を停止し、明示的な不足情報を返す |
| T02 | 月抜け、重複、リターンNaN、予測行欠損 | 無断のゼロ埋め・再正規化なしで停止 |
| T03 | 入力の `available_at` が意思決定後 | 当該行を拒否。全体PIT保証とは別に記録 |
| T04 | 未来の特性・リターンを変更 | 変更より前に確定した予測・ウェイトは不変。評価の実現値だけが変わり得る |
| T05 | データ末尾を切ったprefixで再実行 | 共通の予測原点の出力が一致。入力ハッシュや実行時刻等を比較から除く |
| T06 | 全期間の補完／標準化／特徴選択を意図的に使うnegative fixture | 監査またはfuture mutationテストが検出する |
| T07 | A1グループの固定ウェイト集約 | 予測と実現値に同一ウェイト・同一向きが使われ、手計算と一致 |
| T08 | 各因子の平均を集約した差とスプレッド平均 | 同じ履歴・固定ウェイトなら一致 |
| T09 | 縮小係数gamma=0/0.5/1 | B1、A1とB1の中間、A1へそれぞれ一致。二重縮小なし |
| T10 | gamma=0の戦略とB1 | 初期保有・費用・設定を同じにし、全期間のウェイトとnet損益が一致 |
| T11 | 同一X・同一lambdaの線形Ridge | 個別予測の差と差の直接予測が、clip前に数値許容差内で一致 |

| T16 | 同じOOS入力の再実行 | seed固定で数値一致、順序・浮動小数点の許容差を明示 |
| T17 | 相対ティルトの恒等式 | grossの固定基準との差が b_t * D_(t+1) に一致 |
| T18 | 配分制約 | q_V+q_GM=1、各配分非負、|b|<=上限、事前リスク上限を満たす |
| T19 | 非重複グループ・固定内部重み・無ドリフト | 通常リバランスの因子L1が2*|delta b|へ一致 |
| T20 | 初期購入コスト | factor_pnlはrate、sleeve_totalはrate/(1+rate)。半分にしない |
| T21 | sleeve_totalのドリフト | 次期pretrade比率が w*(1+r)/(1+gross) と一致 |
| T22 | sleeve_totalのnet差分解 | gross差−費用差−費用×gross交差項差に一致 |
| T23 | baseline固定配分 | 毎期固定目標へ戻す。buy-and-holdと混同しない |
| T24 | Dの予測スコア | 2グループ順位ICに依存せず、MSE・OOS R2・方向を手計算と照合 |

| T26 | B1への統計比較 | 同じ月のリターン差からHACと区間を再計算。等ウェイト比のt値を流用しない |

| T28 | 設定・入力欠落・最適化失敗 | 対象工程と理由を記録し、未検証の平均予測で黙って成功扱いしない |

| T30 | E5を実装した場合のQ=0 | 同じ標準化・lambdaの静的Ridgeへ一致。未来平滑化を予測へ使わない |

## テストデータ

同じテストを、①独立なノイズ、②静的線形の予測関係、③緩やかな係数ドリフト、④欠損・極端値・ゼロ分散、の合成データで実施する。ノイズで「全モデルが必ず勝たない」といった確率的条件を通常の単体テストにせず、計算一致と因果的な時点関係を検証する。合成の好成績を実データの根拠にはしない。

## 最小の許容差

恒等式は原則absolute 1e-10／relative 1e-8、最適化の制約は1e-7を初期値とする。ライブラリ差や問題のスケールで変更する場合は理由を残す。大きな違反を事後クリップしてテストを通さない。
