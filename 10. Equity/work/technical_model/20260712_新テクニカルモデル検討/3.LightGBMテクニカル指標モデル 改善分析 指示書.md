# VRP非線形レジームモデル 再設計・OOS検証指示書
## Version 3：Nonlinear Interaction / 5D Relative Return / OOS Validation

# 1. 目的

12カ国株価指数を対象としたクロスセクショナル予測モデルについて、これまでの検証から以下が確認されている。

- 対象資産は12カ国の株価指数
- 各国共通のGlobal VRP系列を使用
- VRP単体には同一時点でクロスセクショナル分散がない
- 一方、VRP水準によってテクニカル特徴量のRank ICが大きく変化する
- BP、DIS25、MOM14等はHigh VRP局面で逆張り効果が強まる
- `rv_shock_20d` はVRP RegimeによってRank ICの符号自体が反転する
- VRP × Local Featureには一定の追加価値が確認されている
- Rolling VRP Betaには明確な追加予測力が確認されていない
- 20営業日より1〜5営業日の予測力が強い
- 12資産しかないため、Daily Rank ICや五分位評価は不安定
- 単純な線形Interactionでは、観測されたVRP依存性を十分表現できない可能性がある

本フェーズでは、

> **VRPをGlobal Regime Variableとして扱い、テクニカル特徴量の効果がVRPに対して非線形に変化するモデルを構築する。**

ことを目的とする。

---

# 2. 今回の最重要変更点

従来モデル：

$$
Y_{i,t}
=
\beta^\top X_{i,t}
+
\gamma^\top
\left(
X_{i,t}\times VRP_t
\right)
$$

では、特徴量 $X$ の実効係数は、

$$
\beta_X+\gamma_X VRP_t
$$

となり、VRPに対して単調・線形にしか変化できない。

しかし実測結果では、例えばBPについて、

```text
Low VRP     : -0.059
Normal VRP  : -0.045
High VRP    : -0.094
```

となっており、

> Normalで効果が弱く、Low / Highで強い

という非単調な構造が確認されている。

したがって、本フェーズでは二次Interactionを追加する。

$$
\boxed{
Y_{i,t}
=
\beta^\top X_{i,t}
+
\gamma^\top
\left(
X_{i,t}\times VRPZ_t
\right)
+
\delta^\top
\left(
X_{i,t}\times VRPZ_t^2
\right)
}
$$

# 3. 主目的変数

主目的変数は、

$$
\boxed{
5D\ Cross\text{-}sectional\ Relative\ Return
}
$$

とする。

まず5営業日先リターンを作成する。

$$
R_{i,t}^{5D}
=
\frac{P_{i,t+5}}{P_{i,t}}-1
$$

```python
df = df.sort_values(["country", "date"])

df["future_return_5d"] = (
    df.groupby("country")["price"].shift(-5)
    / df["price"]
    - 1
)
```

各日時点の12カ国平均を計算する。

$$
\bar R_t^{5D}
=
\frac{1}{N}
\sum_i R_{i,t}^{5D}
$$

相対リターンを、

$$
Y_{i,t}^{5D}
=
R_{i,t}^{5D}
-
\bar R_t^{5D}
$$

とする。

```python
df["mean_return_5d"] = (
    df.groupby("date")["future_return_5d"]
    .transform("mean")
)

df["target_relative_5d"] = (
    df["future_return_5d"]
    - df["mean_return_5d"]
)
```

```text

```

# 5. Target Volatility Adjustmentの検証

国によってボラティリティ水準が大きく異なるため、Vol-adjusted Targetも別モデルとして検証する。

例えば、

$$
Y_{i,t}^{VolAdj}
=
\frac{
R_{i,t}^{5D}
-
\bar R_t^{5D}
}{
\sigma_{i,t}
}
$$

とする。

$\sigma_{i,t}$ は時点 $t$ までの情報のみで計算した20日または60日Realized Volatilityを使用する。

例：

```python
df["target_relative_5d_voladj"] = (
    df["target_relative_5d"]
    / df["rv_20d"]
)
```

ただしこれは単なる単位変更ではない。

国ごとに異なるVolatilityで除算するため、クロスセクショナル順位そのものが変化する可能性がある。

したがって、

```text
Target A：5D Relative Return
Target B：5D Vol-adjusted Relative Return
```

を別ターゲットとしてOOS比較すること。

第一候補はTarget Aとする。

# 8. VRP Z-score

252営業日のRolling Z-scoreを基本とする。

$$
VRPZ_t
=
\frac{
VRP_t-\mu_{t,252}
}{
\sigma_{t,252}
}
$$

```python
vrp_ts = (
    df[["date", "global_vrp"]]
    .drop_duplicates("date")
    .sort_values("date")
    .copy()
)

window = 252

vrp_ts["vrp_mean_252"] = (
    vrp_ts["global_vrp"]
    .rolling(window)
    .mean()
)

vrp_ts["vrp_std_252"] = (
    vrp_ts["global_vrp"]
    .rolling(window)
    .std()
)

vrp_ts["global_vrp_z"] = (
    (
        vrp_ts["global_vrp"]
        - vrp_ts["vrp_mean_252"]
    )
    / vrp_ts["vrp_std_252"]
)

vrp_ts["global_vrp_z2"] = (
    vrp_ts["global_vrp_z"] ** 2
)
```

未来データを利用した全期間標準化は禁止する。

# 9. VRP Regime

診断・解釈用として、

```text
Low
Normal
High
```

を保持する。

例：

```python
def classify_vrp(z):

    if pd.isna(z):
        return np.nan

    if z < -0.5:
        return "Low"

    if z > 0.5:
        return "High"

    return "Normal"
```

ただしモデル本体では原則として、

```text
global_vrp_z
global_vrp_z2
```

の連続値を使用する。

# 10. Local Featureは先にCross-sectional変換する

Interaction生成前にLocal FeatureをクロスセクショナルRank化する。

重要な順序：

```text
Raw Local Feature
        ↓
Cross-sectional Rank
        ↓
VRP Interaction
```

とする。

Raw FeatureとVRPを直接掛けると、国ごとの恒常的な水準差がInteractionへ混入する可能性がある。

---

# 11. Cross-sectional Rank

特徴量 $X$ について、

$$
X_{i,t}^{Rank}
=
RankCS(X_{i,t})
$$

を作る。

```python
local_features = [
    "BP",
    "DIS25",
    "MOM14",
    "RSI_14",
    "rv_shock_20d",
    "rv_20d",
]

for feature in local_features:

    df[f"{feature}_rank"] = (
        df.groupby("date")[feature]
        .rank(
            pct=True,
            method="average"
        )
    )
```

必要に応じてRankを、

$$
[-0.5,\,+0.5]
$$

程度へセンタリングしてもよい。

```python
for feature in local_features:

    df[f"{feature}_rank_centered"] = (
        df[f"{feature}_rank"] - 0.5
    )
```

# 12. Linear VRP Interaction

各CS Rank特徴量について、

$$
VRPZ_t
\times
RankCS(X_{i,t})
$$

を作成する。

```python
for feature in local_features:

    x = f"{feature}_rank_centered"

    df[f"vrp1X_{feature}"] = (
        df["global_vrp_z"]
        * df[x]
    )
```

# 13. Quadratic VRP Interaction

本フェーズで最も重要な追加特徴量。

$$
VRPZ_t^2
\times
RankCS(X_{i,t})
$$

を作成する。

```python
for feature in local_features:

    x = f"{feature}_rank_centered"

    df[f"vrp2X_{feature}"] = (
        df["global_vrp_z2"]
        * df[x]
    )
```

これによって、

```text
Normal VRPでは弱い
Low VRPでは強い
High VRPでは強い
```

といったU字型の効果も表現可能になる。

# 14. Main Effectを必ず残す

Interactionを投入する場合、原則として元特徴量も残す。

例えばBPについて、

```text

VRP² × BP_rank
```

をセットで使用する。

モデル式：

$$

=
\beta_1
+
\beta_2 VRPZ_t
+
\beta_3 VRPZ_t^2
$$

となる。

# 15. Regime Dummy InteractionもRobustness Checkとして作成

二次項モデルとは別に、

$$
X_{i,t}
\times I(LowVRP)
$$

$$
X_{i,t}
\times I(HighVRP)
$$

を作る。

Normal VRPを基準カテゴリーとする。

```python
df["vrp_low"] = (
    df["vrp_regime"] == "Low"
).astype(int)

df["vrp_high"] = (
    df["vrp_regime"] == "High"
).astype(int)

for feature in local_features:

    x = f"{feature}_rank_centered"

    df[f"lowX_{feature}"] = (
        df["vrp_low"] * df[x]
    )

    df[f"highX_{feature}"] = (
        df["vrp_high"] * df[x]
    )
```

これにより、

```text
Low
Normal
High
```

で異なる係数を直接推定できる。

# 24. Scalingのリーク防止

StandardScalerは必ず各Walk-forward WindowのTrainデータのみでfitする。

```text
Train      → fit
Validation → transform only
Test       → transform only
```

全期間でScalerをfitしてはいけない。

PipelineをWindow単位で再fitすること。

---

# 25. Interaction生成とScalingの順序

推奨順序：

```text
① Raw Feature作成
        ↓
② 時点内Cross-sectional Rank
        ↓
③ VRP × Rank Feature
        ↓
④ VRP² × Rank Feature
        ↓
⑤ TrainデータでStandardScaler fit
        ↓
⑥ Ridge学習
```

VRP Z-scoreについても未来データを利用しない。
