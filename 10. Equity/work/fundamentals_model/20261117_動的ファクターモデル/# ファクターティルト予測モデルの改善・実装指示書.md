# ファクターティルト予測モデルの改善・実装指示書

## 1. 役割と目的

あなたは、金融計量経済学、機械学習、時系列予測、ファクター投資に精通したクオンツリサーチャー兼Pythonエンジニアです。

本プロジェクトでは、複数のファクターリターンをPCAによって低次元化し、将来のファクターリターンを予測してファクターティルトに利用するモデルを研究しています。

既存モデルの問題点を診断し、予測精度と経済的価値の改善につながる代替手法をPythonで実装してください。

**最も重要な目的は、予測リターンの変動幅を機械的に大きくすることではなく、アウトオブサンプルで有効な予測シグナルを抽出することです。**

## 2. 現在の研究状況

### 2.1 既存アプローチ

現在の研究では、概ね以下の処理を実施しています。

1. 複数のファクターリターンを取得する。
2. PCAによって共通成分を抽出し、情報を集約する。
3. 主成分を用いて回帰モデルを構築する。
4. 主成分から元のファクターリターンを復元、または将来のファクターリターンを予測する。
5. 得られた予測リターンをファクターティルトに利用する。

ただし、実際の予測対象、PCAの適用対象、回帰の順序、予測ホライズンは既存コードを確認して確定してください。

### 2.2 既に確認されている問題

**Lasso回帰**

- 回帰係数がゼロ、またはゼロに近い値になる。
- 予測リターンの時間変動が極端に小さい。
- 結果として、ファクターティルトに必要な時系列シグナルがほとんど発生しない。

**Ridge回帰**

- 既に実装・検証済み。
- Lassoよりも予測リターンの変動幅が大きくなった。
- しかし、予測精度は悪化した。
- 予測リターンの水準・変動幅を回復させるだけでは問題を解決できないことが確認されている。

したがって、Ridgeを単純な改善策として再提案しないでください。

### 2.3 現時点の仮説

以下の可能性を検証したいと考えています。

- Lassoの正則化が強すぎて有効な予測シグナルまで除去している。
- Ridgeは予測変動を増やす一方、ノイズまで取り込んでいる。
- PCAが分散の大きい成分を優先するため、将来リターンの予測に有効な低分散成分を除外している。
- PCAによる情報集約・復元の過程で予測に必要な情報が失われている。
- ファクターリターンの予測可能性が本質的に低く、一定値に近い予測が統計的に合理的である可能性もある。

これらは確定した原因ではなく、実証的に検証すべき仮説です。

特に、PCAで得られた主成分を予測してから逆変換しているのか、主成分を説明変数として元のファクターリターンを直接予測しているのかを区別してください。

**既存モデルを再現できるまでは、全面的なモデル変更を行わないでください。**

### Phase 1：Lasso/Ridgeの問題診断

まず既存モデルの診断コードを作成してください。

#### 1. 正則化の影響

- 正則化パラメータと非ゼロ係数数の関係
- 正則化パラメータと予測標準偏差の関係
- 正則化パラメータとOOS MSEの関係
- 正則化パラメータとICの関係
- Lassoの係数パス
- Ridgeとの係数・予測分布の比較
- 切片のみのモデルとの比較

#### 2. PCAの情報損失

- 主成分別の寄与率
- 累積寄与率
- 主成分別の将来リターン予測力
- 主成分数とOOS精度の関係
- PCA復元誤差
- 主成分の時系列安定性
- PCAなしの予測モデルとの比較

PCAの再構成精度と将来リターンの予測精度を混同しないでください。

#### 3. 予測値の性質

以下をモデルごとに算出してください。

- 予測値の平均
- 予測値の標準偏差
- 実現リターンの標準偏差
- 予測値と実現値の相関
- 予測誤差
- 予測値の自己相関
- 予測値の符号変化頻度
- ファクター別の予測精度

可能であれば、予測値と実現値の時系列プロット、散布図、分布比較を作成してください。

### Phase 2：既存PCAアプローチの改善

以下の手法を実装し、既存Lasso/Ridgeと比較してください。

#### Model A：Elastic Net

L1とL2の正則化を組み合わせます。

検証対象：

- L1比率
- 正則化強度
- 非ゼロ係数数
- 予測分散
- OOS予測精度

LassoとRidgeの中間的な性質が改善につながるかを確認してください。

#### Model B：Post-Lasso

1. Lassoで説明変数を選択する。
2. 選択された変数だけでOLSを再推定する。
3. 将来リターンを予測する。

係数縮小バイアスの軽減が精度改善につながるかを検証してください。

変数が一つも選択されなかった場合や、選択変数数が学習サンプル数に対して大きすぎる場合の処理も実装してください。

#### Model C：Adaptive Lasso

初期推定値を利用して、変数ごとに異なるL1ペナルティを適用します。

初期推定はRidgeなどを利用できますが、これはRidge単独モデルを改善策として再提案するものではありません。

初期係数がゼロに近い場合の数値安定性を確保してください。

#### Model D：PCA + 正則化パラメータ再設計

現在のPCA構造を維持したまま、以下を検証します。

- 主成分数の変更
- Lassoの正則化強度の変更
- 時系列CVによる選択
- 1-SEルールと最小CV誤差ルールの比較
- 目的変数・説明変数のスケールの影響

予測分散を増やすこと自体を最適化目標にしないでください。

## 4. 次元削減手法の拡張

### Model E：Partial Least Squares（PLS）

通常のPCAでは説明変数の分散を重視しますが、PLSでは説明変数と目的変数の関係を利用して成分を抽出します。

実装要件：

- PLSRegressionを使用する。
- 成分数は時系列CVで決定する。
- PCAベースのモデルと比較する。
- 予測対象が複数ファクターの場合は、多変量PLSも検討する。
- 元のファクターリターンに対する予測値を出力する。

### Model F：Supervised PCA

将来リターンの予測に関連する説明変数を選択した上でPCAを実行します。

実装要件：

1. 学習期間内で説明変数と将来リターンの関係を評価する。
2. 予測に関連する変数を選択する。
3. 選択された変数にPCAを適用する。
4. 抽出した成分で予測モデルを学習する。
5. OOS精度を評価する。

変数選択とPCAの学習は、必ず各学習ウィンドウ内で実施してください。

### Model G：PCAを使用しない直接予測

PCAの必要性そのものを検証するため、元の説明変数から将来のファクターリターンを直接予測するモデルも実装してください。

PCAが予測精度を改善しているのか、逆に有効な情報を除去しているのかを明確にしてください。

## 6. 時系列検証の設計

すべてのモデルについて、公平なアウトオブサンプル比較を実施してください。

### 必須条件

- ランダムなK-Foldを使用しない。
- Expanding WindowまたはRolling Windowを使用する。
- ハイパーパラメータは学習期間内の時系列CVで選択する。
- 標準化・欠損値補完・PCA・変数選択は学習期間だけでfitする。
- 予測時点で利用できない情報を使用しない。
- 予測ホライズンに応じてラベルの重複や情報利用可能時点を考慮する。
- 必要に応じてpurgeやembargoを設ける。
- 同一のOOS期間で全モデルを比較する。
- 最終テスト期間はモデル選択に使用しない。

また、PCAの固有ベクトルの符号反転や、主成分の順序変化が結果に与える影響にも注意してください。

## 7. 評価指標

### 7.1 統計的予測精度

以下を算出してください。

| 指標 | 評価目的 |
|---|---|
| MSE | 予測誤差 |
| MAE | 絶対誤差 |
| OOS R² | ベースラインに対する改善 |
| Pearson IC | 線形的な予測力 |
| Spearman IC | 順位予測力 |
| Directional Accuracy | 符号予測力 |
| Prediction Std | 予測値の変動幅 |
| Calibration | 予測水準と実現値の整合性 |

OOS R²は、事前に定義した過去情報のみを使うベースライン予測と比較してください。

ICは、時系列方向の相関とファクター間のクロスセクション相関を区別してください。

### 7.2 経済的評価

ファクターティルト戦略を構築できる場合、以下も評価してください。

- 年率リターン
- 年率ボラティリティ
- Sharpe Ratio
- 最大ドローダウン
- Turnover
- 取引コスト控除後リターン
- ベンチマークに対する超過リターン
- Information Ratio

予測モデルの改善とポートフォリオ最適化の改善は、別々に検証してください。

ティルトウェイトの制約、リスクモデル、コスト仮定は全モデルで統一してください。
