# 設定・入力ひな形の注意

`config_spec.json`は、新しく実装するValue/GM研究基盤の仕様であり、旧`factor_tilt_research.py --config`との互換性はありません。

`ready_for_real_data`は未設定入力があるためfalseです。既存コード・入力辞書から実際の13本、現行モデル、所属と重み、リターン種別を解決し、監査結果を保存してからtrueに変更します。名称を推測したままtrueにしないでください。

3つのCSVはヘッダーのみで、実データはありません。因子集合の規模と列数は区別してください。`economic_group`の現行の日本語名はアダプタでVALUE／GROWTH_MOMENTUM等へ明示的に対応させます。センチメンタルやQualityを無断で統合・分割しません。

`return_orientation`は、LS因子の向きを統一する管理値です。投資可能なtotal-returnスリーブのリターンに-1を掛けるだけで、実行可能な逆向き資産を作ったことにはなりません。売買・借株・調達を含む定義が必要です。

`experiment_registry.csv`には7系列を定義しています。D1の3成分は診断用であり、ここには別の売買戦略として追加していません。P3は初期設定ですべて無効です。
